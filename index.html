Spatial Audio Tools

Tools for local spatial audio workflows.

Documentation and a browser-based setup helper for preparing HeSuVi audio workflows.

HeSuVi Auto Editor Inspect WAV headers, prepare a local CLI configuration, and follow setup and usage guidance. Apple2Sofa Project page

The browser helper reads WAV header metadata and exports a configuration file. Audio conversion runs locally through the Python CLI; the page does not perform browser-based DSP or upload audio.

Local-first documentation. No analytics or external assets.
